# Contextual references

The following primary sources provide context for secure software development, AI risk governance, policy evaluation, ownership, and supplier assurance. They did not author, validate, or endorse the ZeroUI artifacts.

No line-by-line mapping, equivalence, conformance, or standards alignment is claimed in v0.1.

## Primary sources

- National Institute of Standards and Technology, [AI Risk Management Framework resources](https://www.nist.gov/itl/ai-risk-management-framework/ai-risk-management-framework-resources).
- National Institute of Standards and Technology, [Secure Software Development Framework (SSDF) Version 1.1, SP 800-218](https://www.nist.gov/publications/secure-software-development-framework-ssdf-version-11-recommendations-mitigating-risk).
- Cybersecurity and Infrastructure Security Agency, [Secure by Demand Guide](https://www.cisa.gov/sites/default/files/2024-08/SecureByDemandGuide_080624_508c.pdf).
- Open Policy Agent project, [official documentation](https://www.openpolicyagent.org/docs).
- GitHub, [About code owners](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
- JSON Schema project, [Draft 2020-12 specification](https://json-schema.org/draft/2020-12).

## Referencing policy

Prefer stable pages from the source organization. Record the access date in release-review evidence when interpretation depends on mutable web content. Do not copy substantial passages; summarize in original language and link to the source.

If a future release introduces an external-framework mapping, publish the methodology, source version, reviewer, confidence or caveats, and change-control process alongside the mapping. A reference link alone is not a mapping.
