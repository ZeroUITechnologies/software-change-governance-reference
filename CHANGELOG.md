## [0.1.0] — 2026-10-16

Initial public-reference draft prepared from the canonical ZeroUI website artifacts:

- twelve-control Software Change Governance Control Matrix;
- JSON and CSV representations of the matrix;
- Decision Evidence Record JSON Schema using JSON Schema Draft 2020-12;
- complete synthetic DER example; and
- explicit scope, claim, citation, and versioning documentation.

Version 0.1 is not a stable standard. Breaking changes may be introduced in a future draft with a new versioned path.
