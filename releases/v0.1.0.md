# ZeroUI Software Change Governance Reference v0.1.0

**Tag:** `v0.1.0`  
**Release date:** 2026-10-16  
**Repository:** https://github.com/ZeroUITechnologies/software-change-governance-reference

This is the first public-reference release of two ZeroUI-defined,
tool-neutral artifacts:

- the Software Change Governance Control Matrix v0.1, with twelve controls in
  canonical JSON and equivalent CSV representations; and
- the Decision Evidence Record v0.1, a JSON Schema Draft 2020-12 schema plus a
  complete synthetic example.

The matrix explicitly distinguishes descriptive row-level workflow decisions
from the Decision Evidence Record outcome enumeration.

The DER example uses fictional `ORG-*` policy identifiers so they cannot be
mistaken for control-matrix `SCG-*` identifiers.

## Validation

Run:

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate.py --require-jsonschema
sha256sum --check SHA256SUMS
```

The validator checks JSON/CSV matrix parity, control identifiers and fields,
schema validity, conformance of the synthetic example, and chronological
consistency between a final record and its example deployment event.
