# License decision record — resolved 2026-10-16

This file is retained as the resolution record for the former publication
gate. An authorized ZeroUI owner approved the licensing model on 2026-10-16.
The controlling terms and exact file scopes are in [`LICENSE`](LICENSE).

This file is operational guidance, not legal advice.

## Approved decisions

1. **Implementation materials:** the DER schema, example, validation code,
   dependency file, and workflow automation use Apache License 2.0.
2. **Documentation and data:** prose, citation/release metadata, and the
   control-matrix JSON/CSV data use CC BY 4.0.
3. **Attribution:** the recommended attribution identifies the work, version,
   ZeroUI Technologies LLP, repository URL, license, and modifications.
4. **Patents:** Apache License 2.0 supplies its stated patent grant for the
   materials it covers. CC BY 4.0 does not license patent rights.
5. **Trademarks:** ZeroUI marks are reserved except for customary factual
   attribution, as described in [`TRADEMARKS.md`](TRADEMARKS.md).
6. **Inbound contributions:** every contributed commit requires DCO 1.1
   sign-off and is accepted under the outbound license applicable to its file.
7. **Publisher:** ZeroUI Technologies LLP is the named copyright holder and
   publisher.
8. **Third-party material:** contextual external sources are linked rather
   than copied or relicensed. The official Apache, Creative Commons, and Linux
   Foundation DCO texts are reproduced verbatim under their own stated copying
   permissions.
